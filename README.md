# NotchRP — Notch Roleplay Companion

**NotchRP** adalah aplikasi pendamping roleplay SAMP berupa overlay interaktif (*Dynamic Island*) untuk GTA San Andreas (SA-MP 0.3.DL), dirancang khusus untuk mendukung pengalaman bermain di server Jogjagamers tanpa merebut fokus dari game.

---

## Fitur Utama

1. **Financial & Roleplay Tracker** — Pelacak pencatatan finansial (ledger uang) dan ringkasan data *chatlog* selama bermain, termasuk statistik pekerjaan (*job tracker*) dan *playtime*.
2. **Browser In-Game Overlay** — Akses peramban langsung dari dalam game tanpa perlu keluar jendela, lengkap dengan fitur klik langsung pada iklan atau tautan yang muncul di layar.
3. **Cinematic Camera Control** — Kontrol kamera bebas untuk kebutuhan sinematik dan perekaman momen di dalam game.
4. **Quick Chat AI Translation** — Penerjemahan *chat* dua arah berbasis AI secara instan dengan 3 mode tampilan (*display mode*) untuk memudahkan komunikasi lintas bahasa.
5. **Editor SSRP** — Editor foto bawaan untuk mengolah kebutuhan *Screenshot Roleplay* (SSRP) secara cepat.
6. **Media Lyrics** — Menampilkan lirik musik yang sedang diputar langsung di layar overlay.
7. **Anim Collection** — Simpan dan kelola daftar animasi favorit agar mudah diakses kapan saja.

## Kebutuhan Sistem

* **OS:** Windows 10 / Windows 11 (64-bit)
* **RAM:** Minimum 4 GB
* **Penyimpanan:** 1 GB ruang kosong
* **Game:** GTA San Andreas v1.0 US + SA-MP 0.3.DL
* **Tambahan:** GPS Line *(opsional)* & koneksi internet untuk pembaruan otomatis

---

## Catatan Penggunaan & Privasi

NotchRP selalu diperbarui dan gratis untuk selamanya. Seluruh data diproses secara lokal dan sepenuhnya berada di tangan pengguna. Dianjurkan untuk digunakan pada perangkat pribadi serta selalu memeriksa kondisi aplikasi sebelum meninggalkan perangkat. Gunakan aplikasi ini secara bijak dan penuh tanggung jawab.
